Documentation

Date and time picker pattern

Composition — no runtime template. Reach for it when a single ISO datetime value needs picking.

Usage

Combine on submit. Concatenate the date and time values into an ISO 8601 string on form submit (Alpine: date + 'T' + time + ':00').
