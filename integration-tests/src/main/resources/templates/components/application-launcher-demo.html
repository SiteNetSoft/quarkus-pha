As the application launcher component is now deprecated upstream, an application launcher is built by composing the menu suite: a plain menu toggle with the waffle icon opening a dropdown menu with search, favorites, and grouped items.

The waffle-icon toggle opens a menu with a search filter, favoritable items (star an item to pin it into a Favorites group), grouped items separated by dividers, an external link with a custom icon, a tooltip item, and a disabled item.

Documentation

Application launcher pattern

Composition only — no runtime template. A plain menu-toggle with the waffle icon opens a menu composed of a search input, a dynamic Favorites group fed by star item-actions, titled groups with dividers, and link items (external links carry the external-link icon).

Usage

Anchor right. Standard placement is the far-right of the masthead, next to the user avatar and notifications.
